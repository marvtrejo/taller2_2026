NoteCriterio de la segunda derivada

Para encontrar los puntos máximos y mínimos relativos de una función, utilizamos el siguiente procedimiento:

  1. Obtener la primera derivada \(f'(x)\).
  2. Encontrar los puntos críticos igualando la primera derivada a cero (\(f'(x) = 0\)) y resolviendo para \(x\).
  3. Obtener la segunda derivada \(f''(x)\).
  4. Evaluar los puntos críticos en la segunda derivada para determinar su naturaleza:
    • Si \(f''(x) > 0\), la función es cóncava hacia arriba y tenemos un mínimo.
    • Si \(f''(x) < 0\), la función es cóncava hacia abajo y tenemos un máximo.
  5. Calcular la coordenada \(y\) evaluando el punto crítico en la función original.
  • \(f(x) = x^3 - 3x^2 + 2x - 3\)
  • \(g(x) = x^4 - 4x^2\)
  • \(h(x) = x^2 + 3x + 2\)

1. Primera derivada

\[f'(x) = 3x^2 - 6x+2\]

2. Puntos críticos (\(f'(x) = 0\))

Factorizamos \(f'(x)\), como no es fácilmente factorizable, utilizamos la fórmula general (\(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)):

\[ \begin{aligned} x &= \frac{-(-6) \pm \sqrt{(-6)^2 - 4(3)(2)}}{2(3)} \\ x &= \frac{6 \pm \sqrt{36 - 24}}{6} \\ x &= \frac{6 \pm \sqrt{12}}{6} \end{aligned} \] Simplificando el radical (\(\sqrt{12} = \sqrt{4 \cdot 3} = 2\sqrt{3}\)) tenemos que:

\[ x = \frac{6 \pm 2\sqrt{3}}{6} = 1 \pm \frac{\sqrt{3}}{3} \] Nuestros puntos críticos son:

  • \(x_1 = 1 - \frac{\sqrt{3}}{3}\)
  • \(x_2 = 1 + \frac{\sqrt{3}}{3}\)

3. Segunda derivada \[f''(x) = 6x - 6\]

4. Evaluamos puntos críticos

  • Para \(x_1= 1 - \frac{\sqrt{3}}{3}\):

\[ f''(1 - \frac{\sqrt{3}}{3}) = 6(1 - \frac{\sqrt{3}}{3}) - 6\\ f''(1 - \frac{\sqrt{3}}{3}) = 6- \frac{6\sqrt{3}}{3} - 6\\ f''(1 - \frac{\sqrt{3}}{3}) = - 2\sqrt{3} \]

Por el signo negativo podemos inferor que es un valor menor a cero, por lo tanto hay un máximo.

  • Para \(x_2= 1 + \frac{\sqrt{3}}{3}\):

\[ f''(1 + \frac{\sqrt{3}}{3}) = 6(1 + \frac{\sqrt{3}}{3}) - 6 \\ f''(1 + \frac{\sqrt{3}}{3}) = 6 + \frac{6\sqrt{3}}{3} - 6 \\ f''(1 + \frac{\sqrt{3}}{3}) = 2\sqrt{3} \]

Este valor es mayor a cero, por lo tanto tenemos un mínimo.

5. Coordenadas finales

Evaluamos los puntos críticos en la función original \(f(x)\): * \(x_1 = 1 - \frac{\sqrt{3}}{3}\) * \(x_2 = 1 + \frac{\sqrt{3}}{3}\)

  • \(f(1 - \frac{\sqrt{3}}{3}) = (0.42)^3 - 3(0.42)^2 + 2(0.42) - 3 \approx -2.62 \implies \text{Punto Máximo: } \mathbf{(0.42, -2.62)}\)
  • \(f(1.58) = (1.58)^3 - 3(1.58)^2 + 2(1.58) - 3 \approx -3.38 \implies \text{Punto Mínimo: } \mathbf{(1.58, -3.38)}\)

Evaluamos los puntos críticos exactos en la función original \(f(x) = x^3 - 3x^2 + 2x - 3\). (Nota algebraica: Al desarrollar los binomios al cubo y al cuadrado, muchos términos con raíces se cancelan o simplifican).

  • Evaluando el máximo (\(x = 1 - \frac{\sqrt{3}}{3}\)):

\[ \begin{aligned} f\left(1 - \frac{\sqrt{3}}{3}\right) &= \left(1 - \frac{\sqrt{3}}{3}\right)^3 - 3\left(1 - \frac{\sqrt{3}}{3}\right)^2 + 2\left(1 - \frac{\sqrt{3}}{3}\right) - 3 \\ &= -3 + \frac{2\sqrt{3}}{9} \end{aligned} \] Por lo tanto, el punto máximo: \(\mathbf{\left(1 - \frac{\sqrt{3}}{3}, -3 + \frac{2\sqrt{3}}{9}\right)}\)

  • Evaluando el mínimo (\(x = 1 + \frac{\sqrt{3}}{3}\)):

\[ \begin{aligned} f\left(1 + \frac{\sqrt{3}}{3}\right) &= \left(1 + \frac{\sqrt{3}}{3}\right)^3 - 3\left(1 + \frac{\sqrt{3}}{3}\right)^2 + 2\left(1 + \frac{\sqrt{3}}{3}\right) - 3 \\ &= -3 - \frac{2\sqrt{3}}{9} \end{aligned} \] Por lo tanto, el punto mínimo: \(\mathbf{\left(1 + \frac{\sqrt{3}}{3}, -3 - \frac{2\sqrt{3}}{9}\right)}\)

\(g(x) = x^4 - 4x^2\)

1. Primera derivada \[g'(x) = 4x^3 - 8x\]

2. Puntos críticos (\(g'(x) = 0\))

Primero factorizamos por factor común: \[ \begin{aligned} 4x(x^2 - 2) &= 0 \end{aligned} \] Esto nos da un punto crítico en \(x = 0\).

Para el paréntesis, resolvemos: \[ \begin{aligned} x^2 - 2 &= 0 \\ x^2 &= 2 \\ x &= \pm\sqrt{2} \end{aligned} \].

Nuestros puntos críticos son:

  • \(x = 0\)
  • \(x =+\sqrt{2}\)
  • \(x=-\sqrt{2}\).

3. Segunda derivada \[g''(x) = 12x^2 - 8\]

4. Evaluar puntos críticos

  • Para \(x = 0\): \(g''(0) = -8\). Es menor a cero, por lo tanto hay un máximo.
  • Para \(x = \sqrt{2}\): \(g''(\sqrt{2}) = 12(2) - 8 = 16\). Es mayor a cero, por lo tanto hay un mínimo.
  • Para \(x = -\sqrt{2}\): \(g''(-\sqrt{2}) = 12(2) - 8 = 16\). Es mayor a cero, por lo tanto hay un mínimo.

5. Coordenadas finales

Evaluamos en la función original \(g(x)\):

  • \(g(0) = 0 \implies \text{Punto máximo: } \mathbf{(0, 0)}\)
  • \(g(\sqrt{2}) = (\sqrt{2})^4 - 4(\sqrt{2})^2 = 4 - 8 = -4 \implies \text{Punto mínimo: } \mathbf{(\sqrt{2}, -4)}\)
  • \(g(-\sqrt{2}) = (-\sqrt{2})^4 - 4(-\sqrt{2})^2 = 4 - 8 = -4 \implies \text{Punto mínimo: } \mathbf{(-\sqrt{2}, -4)}\)

\(h(x) = x^2 + 3x + 2\)

1. Primera derivada

\[h'(x) = 2x + 3\]

2. Puntos críticos (\(h'(x) = 0\))

Despejamos \(x\):

\[ \begin{aligned} 2x + 3 &= 0 \\ 2x &= -3 \\ x &= \frac{-3}{2} \end{aligned} \]

Nuestro único punto crítico está en \(x = \frac{-3}{2}\).

3. Segunda derivada

\[h''(x) = 2\]

4. Evaluar puntos críticos

Dado que la segunda derivada es una constante positiva (\(2 > 0\)), cualquier punto que evaluemos será cóncavo hacia arriba. Por lo tanto, en \(x = \frac{-3}{2}\) hay un mínimo.

5. Coordenadas finales

Evaluamos en la función original \(h(x)\):

\[ h(\frac{-3}{2}) = (\frac{-3}{2})^2 + 3(\frac{-3}{2}) + 2 \\ h(\frac{-3}{2}) = \frac{-9}{4}-\frac{9}{2}+\frac{8}{4} \\ h(\frac{-3}{2}) = -\frac{1}{4} \]

Por lo tanto, nuestra coordenada es \(\mathbf{(\frac{-3}{2}, -\frac{1}{4})}\)
